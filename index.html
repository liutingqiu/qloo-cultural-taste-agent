QLOO_API_KEY=... QLOO_BASE_URL=http://127.0.0.1:8787 npm run cli -- \
  --description "shoegaze and slow cinema" --seed artist --domains movie,place --take 5 --out runs/demo
Drop QLOO_BASE_URL and set a real hackathon key to hit https://hackathon.api.qloo.com. The client refuses to answer without a key; it never falls back to a local entity list.
